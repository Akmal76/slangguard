    About this model

    It is IndoBERT with a small LoRA adapter. When the language of new text drifts, the SlangGuard pipeline trains a new adapter and promotes it only if it learns the new slang without forgetting the old. This page follows the promoted model, shown below.

    Limits. The slang drift in the experiments is simulated (real tweets rewritten with a slang lexicon). The model reaches about 0.65 to 0.69 macro-F1 on tweets. It is stored as 8-bit integers so it fits in a web page, which changes the label of about 1% of texts, mostly the ones it is unsure about. Do not use it for decisions about people.

    First visit downloads about 125 MB, and the browser keeps it afterwards.
